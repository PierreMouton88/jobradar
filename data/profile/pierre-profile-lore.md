# Profil long — Pierre Mouton

## Positionnement général

Pierre Mouton est développeur fullstack JavaScript / TypeScript junior, avec une reconversion depuis un parcours business, ressources humaines, coordination et gestion de projets vers le développement web.

Son positionnement principal est :

Développeur Fullstack JavaScript / TypeScript, avec une appétence pour React, NestJS, Prisma, les architectures backend, les données et l’IA appliquée au développement web.

Il recherche plutôt un poste de développeur fullstack, développeur React / Node.js, développeur React / NestJS ou développeur backend junior Node.js / NestJS.

Les contrats recherchés en priorité sont le CDI et le CDD. Les stages et alternances ne sont pas prioritaires.

## Objectifs professionnels

Pierre cherche un poste qui lui permette de progresser techniquement tout en contribuant à un produit concret.

Il souhaite continuer à renforcer ses compétences sur :

- React ;
- TypeScript ;
- Node.js ;
- NestJS ;
- Prisma ;
- PostgreSQL ;
- API REST ;
- architecture backend ;
- tests ;
- Docker ;
- CI/CD ;
- intégration de fonctionnalités IA dans des applications web.

Il est particulièrement intéressé par les projets où l’IA est utilisée de manière concrète et utile, par exemple :

- analyse de données textuelles ;
- structured outputs ;
- validation de sorties IA ;
- embeddings ;
- RAG ;
- agents contrôlés ;
- automatisation de workflows métier ;
- outils internes augmentés par IA.

## Environnements recherchés

Les environnements les plus adaptés sont ceux qui proposent :

- une équipe technique accompagnante ;
- du mentoring ;
- des code reviews ;
- une stack JavaScript / TypeScript moderne ;
- des projets concrets ;
- une vraie logique produit ;
- des pratiques de qualité raisonnables ;
- des sujets backend, données ou IA appliquée ;
- une ouverture aux profils junior en progression.

Pierre peut être pertinent dans une entreprise qui valorise à la fois la compréhension technique et la compréhension métier.

Son ancien parcours en ressources humaines, coordination et gestion de projets peut être utile pour comprendre les besoins utilisateurs, communiquer avec des équipes non techniques et traduire des besoins métier en fonctionnalités.

## Environnements à éviter

Les environnements moins adaptés sont ceux qui demandent :

- une autonomie totale immédiate sans accompagnement ;
- un niveau senior déguisé ;
- plusieurs années d’expérience ferme sur une stack précise ;
- une mission principalement commerciale sans vraie pratique de développement ;
- une stack trop éloignée de JavaScript / TypeScript ;
- du scraping agressif ou juridiquement fragile ;
- de l’IA utilisée comme argument marketing sans base technique solide ;
- une alternance ou un stage uniquement.

## Points à valoriser en candidature

Pierre peut valoriser :

- son profil fullstack JavaScript / TypeScript ;
- sa capacité à construire une application complète avec frontend, backend, base de données et IA ;
- son expérience React / TypeScript / Tailwind ;
- son expérience NestJS / API REST / Prisma ;
- sa compréhension de la modélisation de données ;
- son usage de Docker, AWS, Nginx et CI/CD sur des projets précédents ;
- sa capacité à apprendre vite et à documenter ses choix ;
- son projet JobRadar IA comme preuve d’apprentissage autonome et structuré ;
- son intérêt pour l’IA appliquée de manière concrète au développement web.

## Points de vigilance à gérer

Pierre doit éviter de se présenter comme expert IA senior.

La bonne formulation est plutôt :

Développeur fullstack junior avec une appétence forte pour l’IA appliquée, capable d’intégrer des briques LLM, RAG et structured outputs dans une application web.

Il faut valoriser le projet JobRadar IA comme un projet portfolio sérieux, mais rester clair sur son caractère pédagogique.

## Style de présentation recommandé

En candidature, le ton doit être :

- clair ;
- concret ;
- humble ;
- orienté produit ;
- orienté progression ;
- crédible techniquement.

Il faut éviter les formulations trop grandiloquentes comme “expert IA” ou “architecte IA”.

Il faut préférer :

- “j’ai construit un projet portfolio complet autour du scraping, de PostgreSQL, de Prisma, des embeddings, du RAG et des agents contrôlés” ;
- “j’apprends à intégrer l’IA dans des applications web concrètes” ;
- “je cherche une équipe où continuer à progresser en contribuant à un produit réel”.

## Points négatifs dans une offre

Une offre est moins pertinente si elle mentionne :

- senior obligatoire ;
- autonomie totale dès le premier jour ;
- plus de trois ans d’expérience obligatoire ;
- stack très éloignée sans accompagnement ;
- stage ou alternance uniquement ;
- mission commerciale plus que technique ;
- environnement flou ;
- projet IA sans vraie base technique ;
- responsabilités trop larges pour un profil junior.
